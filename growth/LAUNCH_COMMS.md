## Section 5 — Landing Page A/B Tests (top 5)

À mettre en place une fois civique.fr stabilisé, via feature flag simple (cookie 50/50 ou similaire). Lancer les tests un par un — pas en parallèle — pour ne pas brouiller les signaux.

### Test 1 — Hero Headline

| | Variante |
|---|---|
| **A (contrôle)** | « Réussir votre examen civique, à votre rythme » |
| **B** | « Préparez votre entretien préfectoral en 6 langues » |
| **Hypothèse** | La mention « 6 langues » réduit la friction cognitive pour les visiteurs L2 et augmente l'auto-identification. |
| **Métrique de succès** | Taux de signup (inscription complétée) parmi les sessions ayant scrollé > 50% du fold. |
| **Volume requis** | ~2 000 visiteurs / variante avant lecture. |

### Test 2 — CTA principal

| | Variante |
|---|---|
| **A (contrôle)** | « Commencer ma préparation » |
| **B** | « Essayer gratuitement » |
| **Hypothèse** | « Essayer gratuitement » lève la barrière d'engagement perçue et augmente le clic, mais peut attirer une audience moins qualifiée. |
| **Métrique de succès** | Taux de signup, ET taux d'activation J+2 (au moins 1 entraînement complété). |
| **Risque** | Si B gagne en clic mais perd en activation, contrôle reste meilleur. |

### Test 3 — Témoignage flottant

| | Variante |
|---|---|
| **A** | Témoignage Amina (prénom féminin, Marseille) |
| **B** | Témoignage masculin (ex. Karim, Lille) |
| **C** | Pas de témoignage |
| **Hypothèse** | Le témoignage augmente le taux de conversion ; le genre du prénom influence l'identification selon le visiteur. |
| **Métrique de succès** | Taux de signup. Test secondaire : durée de session. |
| **Note** | Test à 3 branches → besoin de volume. Ne lancer que si trafic > 5 000 visites/sem. |

### Test 4 — Affichage du prix

| | Variante |
|---|---|
| **A (contrôle)** | « À partir de [X]€ » dans le hero, prix complets en bas |
| **B** | Tableau de prix complet visible dès le hero |
| **Hypothèse** | Montrer les prix tôt filtre les visiteurs (moins de signups, mais signups plus qualifiés → meilleure conversion premium). |
| **Métrique de succès** | Taux de conversion vers offre payante à J+14. |

### Test 5 — Hero asset

| | Variante |
|---|---|
| **A (contrôle)** | Animation « threads » (fils tissés, design Tisserand) |
| **B** | Photo statique d'un espace de préparation réel (table, café, fiches) |
| **Hypothèse** | La photo est plus chaleureuse et concrète pour notre audience adulte 25-50 ans. L'animation est plus moderne mais peut paraître froide. |
| **Métrique de succès** | Taux de signup + temps avant premier scroll (proxy d'engagement immédiat). |
| **Note** | Vérifier la performance mobile : une animation lourde peut tuer le LCP. |
