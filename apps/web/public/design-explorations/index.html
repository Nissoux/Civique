— Choisir une direction visuelle

Trois identités
radicalement différentes.

Chaque prototype est complet (hero, programme, auth) et peut être ouvert en plein écran. Les trois ne sont pas des variations sur le même thème — chacun défend une vision distincte du produit.

L'Atelier

— Éditorial

Magazine intellectuel français. Papier crème, oxblood, serif Fraunces. Pour un produit qui se lit comme une revue savante.

Display : Fraunces (variable serif)
Body : Bricolage Grotesque
Mode : clair, papier · 1 voie

Hexagone

— Architectural

Beta.gouv meets Linear. Navy + terracotta, blueprint grid, carte hexagonale animée. Pour un produit administratif premium.

Display : Instrument Serif
Body : Manrope · Mono : JetBrains
Mode : sombre · grille blueprint

Tisserand

— Multiculturel

Chaleureux, tissé, multilingue. Bone + saffron + aubergine, fils tissés, témoignage flottant. Pour un produit qui accueille la diversité linguistique.

Display : Newsreader (italics)
Body : Karla
Mode : clair, ton chaud · 5 voix
Quand choisir L'Atelier ?
Si tu veux qu'on perçoive Civique comme une institution culturelle sérieuse — un livre qu'on consulte. Risque : peut intimider les utilisateurs L2.
Quand choisir Hexagone ?
Si tu veux que Civique inspire confiance par sa rigueur — comme un dossier officiel bien fait. Risque : peut sembler froid sans contre-poids humain.
Quand choisir Tisserand ?
Si tu veux que les utilisateurs se sentent attendus, accueillis. La diversité linguistique est célébrée, pas cachée. Le plus chaleureux des trois.
